# 🛰️ EcoOrbit — Система мониторинга экологических выбросов

> Командный центр мониторинга промышленных выбросов с интеграцией спутниковых данных NASA GIBS и ИИ-аналитикой для обнаружения аномалий и прогнозирования экологических рисков.

EcoOrbit отслеживает уровень загрязнения воздуха вокруг крупных промышленных объектов Узбекистана (горно-металлургические комбинаты, НПЗ, ТЭЦ, цементные заводы) в реальном времени. Система объединяет **наземные датчики**, **спутниковые снимки NASA GIBS** и **модели машинного обучения** для выявления скрытых паттернов загрязнения — например, ночных сбросов или роста выбросов в выходные.

---

## 🎯 Что умеет проект

| Страница | Возможности |
|---|---|
| **Глобальная карта** | Интерактивная карта (Leaflet) с реальными заводами Узбекистана, рейтингом AQI и зонами загрязнения. Переключение спутниковых слоёв NASA GIBS: реальные цвета (MODIS/VIIRS), аэрозоли (AOD), NO₂, тепловые аномалии, NDVI |
| **Рейтинг экологии** | Эко-балл (0–100) и индекс AQI для всех объектов, таблица спутниковых индикаторов, топ «чистых» и «грязных» заводов |
| **ИИ-прогнозы** | Прогноз концентрации CO₂ / NO₂ на ближайшие часы, автоматический анализ угроз и превышений норм ВОЗ |
| **Анализ поведения** | Детекция скрытых паттернов: ночные выбросы (22:00–06:00), деятельность в выходные, деградация растительности (NDVI), аэрозольная нагрузка |

### Ключевые функции
- 📡 **Реальные спутниковые данные NASA GIBS** — снимки MODIS, VIIRS, OMPS с ежедневным обновлением
- 🤖 **ИИ-обнаружение аномалий** на основе Isolation Forest
- 🧮 **Eco Score** — собственная метрика экологического состояния объекта (0–100)
- 🔮 **Прогнозирование** трендов выбросов на основе модели анализа временных рядов
- ⚠️ **Поведенческий анализ** для выявления нелегального сброса отходов

## 🧱 Архитектура

```
EcoOrbit
├── backend/            # FastAPI + SQLAlchemy + scikit-learn
│   ├── main.py         # REST API (emissions, anomalies, forecast, behavior)
│   ├── ml_model.py     # ИИ: Isolation Forest, Eco Score, прогноз, поведение
│   ├── models.py       # SQLAlchemy-модели + Pydantic-схемы
│   ├── database.py     # SQLite + SQLAlchemy engine
│   └── seed_data.py    # Симулятор: 7 дней истории + real-time данные
│
└── frontend/           # React 19 + Vite + Leaflet + Recharts
    └── src/
        ├── pages/          # Карта, Рейтинг, ИИ-прогнозы, Поведение
        ├── components/     # EcoMap, Dashboard, Navbar
        └── context/        # Данные заводов + конфигурация NASA GIBS
```

### API endpoints (бэкенд)
| Метод | URL | Описание |
|---|---|---|
| `GET` | `/api/emissions` | История замеров выбросов |
| `POST` | `/api/emissions` | Добавить замер (с расчётом Eco Score и детекцией аномалии) |
| `GET` | `/api/anomalies` | Найденные аномалии |
| `GET` | `/api/forecast/{region}` | Прогноз выбросов для региона |
| `GET` | `/api/behavior/{region}` | Поведенческий анализ региона |

## 🚀 Быстрый запуск

### 1. Backend (FastAPI)
```bash
cd backend
python -m venv venv

# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install fastapi uvicorn sqlalchemy scikit-learn pandas numpy requests
uvicorn main:app --reload
```
API: http://localhost:8000

### 2. Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
Фронтенд: http://localhost:5173

### 3. Наполнение данными (симулятор)
При запущенном бэкенде:
```bash
cd backend
python seed_data.py
```
Скрипт загрузит исторические данные за 7 дней и перейдёт в режим генерации данных в реальном времени.
